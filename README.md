# NITO EXPLOR — Static Website

A premium, responsive static website built with:
- HTML
- CSS
- JavaScript

## Files

- `index.html` — main website
- `styles.css` — design and responsive styling
- `script.js` — mobile navigation, policy accordion and footer year
- `assets/nito-explor-logo.png` — NITO EXPLOR logo

## Before publishing

Replace the placeholders with information confirmed by the client:

1. Park banner image
2. Park/gallery images
3. Phone number
4. Email address
5. Physical address
6. Google Maps location
7. Opening hours
8. Tour/experience names
9. Prices
10. Official park description
11. Official booking procedure
12. Final terms, cancellation/refund and safety policies

## Important

This version intentionally has no backend and no online booking system. Visitors contact the park by phone/email to make bookings.

## GitHub Pages

Upload the files to a GitHub repository and enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → /root

The site is static and does not require PHP, Laravel, a database or a server-side booking system.
